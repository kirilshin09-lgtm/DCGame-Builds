# DCGame — билды

Готовые WebGL-билды игры Digital College.

**Играть:** https://kirilshin09-lgtm.github.io/DCGame-Builds/

Текущая сборка — **2026-09-23**: актуальная локальная версия проекта, обновлённый интерфейс и графика, еда, игровые часы, смена дня и ночи, награды и эффекты шагов.

Unity 6000.5.2f1, WebGL, Brotli с Decompression Fallback. Сцены: MainMenu → New Scene. Сборка завершена без ошибок.

Серверные функции менторов требуют отдельно опубликованного HTTPS API; адрес API в этой сборке по умолчанию локальный.

Исходники: https://github.com/kirilshin09-lgtm/DCGame
