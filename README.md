# DCGame — билды

Готовые WebGL-билды игры Digital College.

**Играть:** https://kirilshin09-lgtm.github.io/DCGame-Builds/

Текущая сборка — **2026-10-02**: цепочки побочных заданий студентов, усложняющиеся мини-игры, свайпы по стрелкам в заданиях с принтером, увеличенное окно попадания в музыкальных заданиях и разные цвета левого и правого каналов.

Unity 6000.5.2f1, WebGL, Brotli с Decompression Fallback. Сцены: MainMenu → New Scene. Сборка завершена без ошибок; файлы локализации включены.

Серверные функции менторов требуют отдельно опубликованного HTTPS API; адрес API в этой сборке по умолчанию локальный.

Исходники: https://github.com/kirilshin09-lgtm/DCGame
